# PureMusic V8.8 – Smart Queue & Library

**by Ho Tan**

## Thay đổi
- Ghi nhớ hàng chờ và vị trí bài hát qua lần tải lại trang.
- Gợi ý tiếp tục nghe, chỉ phát sau khi người dùng nhấn nút.
- Smart Shuffle hạn chế lặp nghệ sĩ và bài mới nghe.
- Lưu hàng chờ thành playlist, xóa các bài sắp phát.
- Giữ nguyên OAuth, Google Drive, OneDrive, FLAC, Hi-Fi Direct, Audio Lab.

## Giới hạn
- Trạng thái lưu trên thiết bị hiện tại, không đồng bộ giữa iPhone và Windows.
- Nếu access token cloud hết hạn, cần đăng nhập lại để phát.
- Chưa có streaming FLAC HTTP Range thực sự.
- Cần kiểm thử thực tế trên Safari iPhone.
