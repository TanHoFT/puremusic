# PureMusic V10.0 – Obsidian UI

**by Ho Tan** · PWA · Google Drive / OneDrive

## Cập nhật
- Hệ thống màu graphite, typography, spacing, tương phản và biểu tượng đồng nhất hơn.
- Thư viện: lưới 2 cột trên điện thoại / 4 cột trên desktop, bộ lọc và hàng bài hát rõ ràng.
- Trình phát: bố cục ảnh bìa, tiến trình, điều khiển, mini player được cân chỉnh.
- Audio Lab/Cài đặt: chuẩn hóa card, khoảng cách, trạng thái focus.
- Hỗ trợ Reduce Motion, bàn phím, vùng chạm tối thiểu cho các điều khiển chính.
- Cập nhật phiên bản trong Cài đặt lên 10.0.0 và cache PWA.

## Phạm vi
Bản V10.0 tập trung thay đổi UI. OAuth, Google Drive, OneDrive, phát FLAC, hàng chờ, Audio Lab và chế độ phát nền được giữ từ V9.2. **Chưa tái cấu trúc toàn bộ 19 khối JavaScript cũ**.

## Cài đặt
Giải nén ZIP và tải các file lên thư mục gốc repository GitHub Pages. Chờ Pages triển khai, đóng/mở lại PWA nếu giao diện còn lưu cache.

## Giới hạn
Chưa kiểm thử trực tiếp với tài khoản Drive, iPhone hoặc loa của người dùng. Không cam kết bit-perfect trên PWA.
