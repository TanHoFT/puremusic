PureMusic V7.3 – by Ho Tan

Nâng cấp giao diện điều khiển phát nhạc: thay emoji bằng icon SVG vector, bố cục 5 nút cân đối, nút phát lớn, thanh tiến trình mảnh, trạng thái phát/tạm dừng và lặp lại. Giữ Google Drive, OneDrive, thư viện, hàng chờ, lời bài hát và Audio Lab.

Upload toàn bộ file vào thư mục gốc repository GitHub Pages; ghi đè các file trùng tên. Không cần cấu hình OAuth lại.

Lưu ý: Chưa kiểm thử trực tiếp Safari iPhone; các giới hạn PWA vẫn tồn tại.
